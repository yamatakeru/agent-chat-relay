# アダプターは Go で実装する

> ADR 0007 で、TypeScript と Bun に置き換えました。

保守はエージェントに任せる前提なので、人が慣れているかどうかではなく、客観的な利点で言語を選びました。Go を選んだ理由は 3 つあります。1 つ目は、cc-connect 本体と同じ言語なので、バージョンを固定した接続先の実装と直接突き合わせられることです。2 つ目は、将来、本体のネイティブ platform に移植するときに書き直しが少なくて済むことです。3 つ目は、単一のバイナリで常駐させやすいことです。Go は mise でプロジェクトローカルにインストールします。

## Considered Options

- TypeScript：試行錯誤が速く、MulmoClaude の実装の一部を流用できる。ただし、流用候補の LINE WORKS の実装は 1 対 1 専用で、流用できる範囲は限られる。
