# アダプターは Go で実装する

保守はエージェントに任せる前提のため、人が慣れているかどうかではなく、客観的な利点で言語を選んだ。Go を選んだ理由は 3 つある。cc-connect 本体と同じ言語なので、固定したバージョンの接続先の実装と直接突き合わせられる。将来、本体のネイティブ platform へ移植するときに書き直しが少ない。単一バイナリで常駐させやすい。Go は mise でプロジェクトのローカルに導入する。

## Considered Options

- TypeScript：試行が速く、MulmoClaude の実装を一部流用できる。ただし、流用候補の LINE WORKS 実装は 1 対 1 専用で、流用できる範囲は限られる。
