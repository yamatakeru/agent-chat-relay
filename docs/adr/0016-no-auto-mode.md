# ハーネスのオートモードは採らない

#23 の検討の中で、承認の依頼そのものを減らす方策として、ハーネスのオートモード（Claude Code の `auto`。人の代わりに分類器が実行の可否を決める）を、起動時に選べるようにする案が出ました（#31）。#23 は、承認依頼の束（ADR 0014）と「常に許可」（ADR 0015）で解けたので、この案は別に調べました（2026-11-16）。

## 分かったこと

**Claude Code のオートモード**（公式の文書と、Anthropic の解説 "How we built Claude Code auto mode"）

- 分類器が見るのは、ユーザーの発言とツールの呼び出しです。ユーザーの発言が操作をはっきり名指ししていれば、既定の禁止（`soft_deny`）を解除します（例：「この branch を force-push して」）。
- 作業ディレクトリの中の編集は、分類器を通さずに許可します。自分の設定ファイル（`.claude/` などの保護されたパス）への書き込みは、分類器が判断します。実際に、ユーザーとして頼むと、`.claude/settings.local.json` に許可を書けました（#31 のコメント）。
- 解説が公表した時点で、実際の行き過ぎた操作の 17% を見逃しています。解説自身が、慎重な人間の承認の代わりにはならないと書いています。
- Claude Code は、端末の対話ではオートモードを既定にしています。頼む人と承認する人が同じ、という前提の設計です。

**似た製品**

| 製品 | 誰が頼めるか | 承認を外すときの代わり |
|---|---|---|
| Claude Code Channels（公式のチャットの橋渡し） | 送信者の許可リスト | 外さない。承認の依頼をチャットへ中継する。無人で動かすなら、bypass を信頼できる環境でだけ使うよう案内する |
| Claude Tag（Slack） | 既定ではチャンネルの誰でも | スレッドごとの使い捨てのサンドボックス、資格情報をサンドボックスに置かない、送信先を既定で拒否する |
| GitHub Copilot coding agent、Cursor と Codex のクラウド版 | リポジトリに書き込める人など | VM の隔離とファイアウォール。取り消せない操作は人が確かめる（PR を作るだけ） |
| OpenClaw | ペアリングと許可リスト | サンドボックスとツールの制限。実行の承認は隔離ではないとし、1 つの gateway を 1 つの信頼の境界とする |
| Codex CLI | 本人 | OS のサンドボックスが先にあり、別のエージェントの審査（auto-review）は、サンドボックスの外に出る操作にだけ使う |

どれも、人の承認を外すときは、閉じ込め（隔離、送信先の制限、資格情報の分離）か、頼める人の限定とセットにしています。分類器は、それに重ねる補助です。

**中継に当てはめると**

- 中継では、登録したルームの誰の発言も、分類器にとっての「ユーザーの発言」になります。承認者でない人の発言でも、操作を名指しすれば、禁止が解除されます。
- 中継には、閉じ込めの仕組みがありません。Bash、ネットワーク、作業ディレクトリの外、claude.ai のコネクタの操作が、人を通らなくなります。
- モードはセッション単位で、セッションは全ルームで 1 つです。「承認者だけのルームでオートモードにする」ことは、そのままではできません。
- 採るなら、自分の設定への書き込みの禁止（`--restricted` や `deny` ルール。ACP のアダプター経由で渡せるかは未確認）と、セッションの途中のモードの変化の監視が要ります。claude-agent-acp は、オートモードに対応しないモデルに切り替わると `acceptEdits` に落とします。対応するハーネスも、今は Claude Code だけです。

## 決めたこと

- ハーネスのオートモードは採らない。実行承認を、安全策の要のままにする。
- 次のどちらかが入ったときに、再検討する。
  - 閉じ込め（作業ディレクトリの外に書けない、決めた送信先にしかつなげない、資格情報を置かない、など）
  - ルームごとにセッションを分ける仕組み（全員が承認者のルームだけで、承認を緩められるようになる）

## Considered Options

- **全員を信頼する運用者向けに、起動時に選べるようにする。** 依頼はほぼなくなる。ただし、上の対策が未確認の部品に頼り、#23 は別の方法で解けているので、今作る理由が弱い。
- **開けたまま保留する。** 調べた結果が issue に散らばったままになる。
