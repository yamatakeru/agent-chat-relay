# チャット用ツールは、実行承認なしで使える

AGENTS.md では、ハーネスの実行承認の設定は安全境界であり、緩めるときは ADR に理由を残すと決めている。チャット用ツール（`reply`・`fetch_messages`・`download_attachment` など）を、承認なしで使えるようにする（2026-11-09）。

エージェントは、返事も `reply` で送る。Claude Code の default モードは、MCP のツールにも承認を求める。そのままでは、返事のたびに承認者へ DM が届き、許可するまで返事がルームに出ない。

- Claude Code では、`permissions.allow` に `mcp__chat` を入れる。ほかのハーネスでも、同じ扱いにする。
- 送り先の制限は、中継の側で行う。送れるのは、登録したルームと、許可リストの人の DM だけ。
- ファイルの編集、コマンドの実行、Web の取得などは、これまでどおり毎回承認を求める。

## Considered Options

- **`reply` にも承認を求める。** 意図しない投稿は起きない。ただ、返事のたびに承認が要り、LINE では承認依頼のたびに Push の通数も使う。
- **依頼のあったルームへの `reply` だけを承認なしにする。** 意図しないルームへの投稿は防げる。ただ、別のルームへ知らせるという、単一セッションにした目的の一つが承認待ちになる。

## Consequences

- エージェントは承認なしで、登録したどのルームにも投稿でき、登録したルームの記録を読める。あるルームの発言でエージェントを操り、別のルームへ投稿させたり、別のルームの記録を読ませたりできてしまう（プロンプトインジェクション）。1 つのセッションにまとめるのは、信頼できる人のルームだけにする（ADR 0006）。
- `download_attachment` は、作業場所の `.relay/inbox/` にファイルを書く。中身を読むのは、ハーネスの読み取りの権限に従う。
