# チャット用ツールは、実行承認なしで使える

AGENTS.md では、ハーネスの実行承認の設定は安全境界であり、緩めるときは ADR に理由を残すと決めています。この ADR では、チャット用ツール（`reply`・`fetch_messages`・`download_attachment` など）を、承認なしで使えるようにします（2026-11-09）。

エージェントは、返信も `reply` で送ります。Claude Code の default モードでは、MCP のツールにも承認が必要です。そのままでは、返信のたびに承認者に DM が届き、許可するまで返信がルームに表示されません。

- Claude Code では、`permissions.allow` に `mcp__chat` を追加します。ほかのハーネスでも同じ扱いにします。
- 送信先の制限は中継の側で行います。送信できるのは、登録したルームと、許可リストの人の DM だけです。
- ファイルの編集、コマンドの実行、Web からの取得などには、これまでどおり毎回承認を求めます。

## Considered Options

- **`reply` にも承認を求める。** 意図しない投稿は起きない。ただし、返信のたびに承認が必要になり、LINE では承認依頼のたびに Push の通数も消費する。
- **依頼のあったルームへの `reply` だけを承認なしにする。** 意図しないルームへの投稿は防げる。ただし、別のルームに知らせるという、単一のセッションにした目的の 1 つが承認待ちになってしまう。

## Consequences

- エージェントは承認なしで、登録したどのルームにも投稿でき、登録したルームの記録を読めます。そのため、あるルームの発言でエージェントを操作し、別のルームに投稿させたり、別のルームの記録を読ませたりできてしまいます（プロンプトインジェクション）。1 つのセッションにまとめるのは、信頼できる人がいるルームだけにします（ADR 0006）。
- `download_attachment` は、作業場所の `.relay/inbox/` にファイルを書き込みます。その中身を読めるかどうかは、ハーネスの読み取り権限に従います。
