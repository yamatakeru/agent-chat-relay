# 承認者は、ハーネスが示した「常に許可」を選べる

中継はこれまで、実行承認でいつも「今回だけ許可」を選び、「常に許可」（ACP の `allow_always`）は選びませんでした。そのため、同じツールを何度呼んでも、そのたびに承認者が答える必要がありました。#23 の場面（カレンダーの MCP ツールを並列に呼ぶ）では、依頼を束にしても（ADR 0014）、予定を確かめるたびに承認が要ります。

ACP では、「常に許可」の範囲（ツール、コマンド、ディレクトリなど）と記憶はエージェントが持ち、範囲は選択肢の名前に示すとされています。Claude Code（claude-agent-acp 0.101.0）で確かめると、次のとおりでした（2026-11-16）。

- MCP ツールには、ツール単位の「常に許可」を示す。作業ディレクトリの `.claude/settings.local.json` に書かれ、中継を再起動しても続く。
- 作業ディレクトリの外の読み取りには、ディレクトリ単位でセッションのあいだだけの「常に許可」を示す。
- Bash の書き込み（`touch`・`mkdir`）や、削除などの安全確認の依頼には示さない。
- 計画の承認（ExitPlanMode。`kind` は `switch_mode`）では、「常に許可」の選択肢が、セッションのモードを auto や bypassPermissions に切り替える。
- ファイルの編集（`kind` は `edit`）では、セッションのあいだ編集をすべて許す選択肢になる。`.claude/` の中のファイルでは、自分の設定の編集を許す選択肢になる。

## 決めたこと

- ハーネスが `allow_always` の選択肢を示した依頼では、承認者が「常に許可」を選べるようにする。依頼の文面には、選択肢の名前をそのまま範囲として書く。中継は範囲を推測しない。選択肢が複数あれば、先頭の 1 つを使う。
- モードの切り替え（`kind` が `switch_mode`）とファイルの編集（`edit`）の依頼には、「常に許可」を出さない。ACP の標準の分類で判定するので、ハーネスに依らない。
- ボタンは、LINE と Discord で「許可」「常に許可」「拒否」の 3 つにする。文字では `always <ID>` で答える（Chatwork はこれだけ）。
- 承認依頼の束では、束のすべての依頼に「常に許可」が示されたときだけ、束全体への「常に許可」を出す。示されていない依頼に `always` で答えた場合は、今回だけの許可として扱う。
- 記憶された許可の取り消しは、管理者が端末で行う。チャットからの取り消しは作らない。

## Considered Options

- **今までどおり「今回だけ許可」だけにする。** 許可が残らない。ただし、同じツールでも毎回答える必要があり、#23 の場面の手間が減らない。
- **ハーネスのオートモードで、承認の依頼そのものを減らす。** 依頼はほぼなくなる。ただし、依頼する人と承認する人の分離を手放す。オートモードでは、エージェントが承認なしで自分の許可の設定を書き換えられることも分かった。#31 で別に検討する。
- **束の中に「常に許可」を示されていない依頼があっても、束全体への「常に許可」を出す。** 押す回数は減る。ただし、1 つのボタンの効き目が依頼ごとに変わる。
- **ファイルの編集にも「常に許可」を出す。** 編集の多い作業では答える回数が減る。ただし、セッションのあいだ編集の承認がまとめて外れ、`.claude/` の中では自分の設定の編集まで許すことになる。
- **作業ディレクトリの `.claude/` などへの書き込みの依頼を、中継が見分けて「常に許可」を外す。** ハーネスに特有のパスの一覧が要り、Bash を通した書き込みは見分けられない。また、その書き込みは「今回だけ許可」でも成立するので、守れる範囲がほとんど増えない。

## Consequences

- #23 の場面では、承認者が一度「常に許可」を選べば、以後そのツールでは依頼が来ません。
- 記憶された許可は、ハーネスの設定に残ります。Claude Code では作業ディレクトリの `.claude/settings.local.json` で、中継を再起動しても続きます。何を許したかは、このファイルで確かめます。
- 承認者は、作業ディレクトリの `.claude/` と `.mcp.json` への書き込みの依頼を許可してはいけません（`docs/relay.md` に書く）。「今回だけ許可」でも、ハーネスの許可そのものを書き換えられます。
- 「常に許可」を示すかどうかと範囲は、ハーネスによって変わります。Claude Code 以外のハーネスでは、実行承認が働くようになった時点で確かめます（#6）。
