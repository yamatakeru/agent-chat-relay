# Claude が返す画像は、推測できない URL で 7 日間公開して LINE に渡す

LINE の Bot は、画像を LINE に直接アップロードできません。画像メッセージには HTTPS の URL を渡し、LINE がその URL から画像を取得します。認証を付ける方法はありません。また、LINE は画像を保存せず、開かれるたびに URL から取得するので、URL が無効になると過去の画像も開けなくなります。

ユーザーと相談し、Claude が `cc-connect send --image` で返した画像を、アダプターが公開して LINE に渡すことにしました（2026-11-07）。

- アダプターは画像を `.local/line/media/` に保存し、Webhook と同じトンネルで `/media/<名前>` として公開します。名前は 256 ビットの乱数にし、一覧は公開しません。
- 7 日経ったら削除します。受け取った添付ファイルと同じ期間です。
- 公開 URL のホスト部分は、署名を検証した Webhook が届いたホスト名（`X-Forwarded-Proto: https` のときの `Host`）から決めます。こうすると Quick Tunnel でも設定が不要です。固定の URL を使う場合は `CCJ_LINE_PUBLIC_URL` で指定します。
- URL はログに出力しません。送信のたびにルームでの承認が必要なので、意図しない画像が公開されることはありません。

（2026-11-09 追記）cc-connect の利用をやめたあとも、公開の方式は引き継ぎました。画像はチャット用ツールの `reply` で返すようになり、承認は不要になりました（ADR 0009）。保存場所は `.local/relay/media/` に、固定 URL の指定は `RELAY_PUBLIC_URL` に変わりました。

## Considered Options

- 画像を返さない。作業ディレクトリの中身が外部に出る経路はできないが、Claude が作った図やグラフを LINE で見られない。
- 公開期間を 1 日などに短くする。公開している時間は減るが、それより前の画像は LINE で開けなくなる。

## Consequences

- URL を知っている人なら、誰でも 7 日間閲覧できます。画像を開いた人や、転送された人も含みます。通信は Cloudflare を経由するので、Cloudflare からは中身が見えます（Webhook と同じです）。取得元が LINE か利用者の端末かは区別できない（LINE は取得元の IP を公開しておらず、User-Agent は偽装できる）ため、取得元による制限はしません。
- Quick Tunnel は起動のたびに URL が変わります。アダプターを再起動すると、それより前に返した画像は開けなくなります。Named Tunnel にすれば解消します。
- トンネルで公開する範囲が、Webhook のエンドポイントだけから、`/media/` を加えたものに広がります。
