# メンションのない発言への返事の評価

受信モードが「すべて」か「他人宛てを除く」のルームでは、メンションのない発言もエージェントに届きます。そのとき、Bot を暗に含む問いかけには答え、ほかの人どうしの会話には黙るように、案内（`src/core/instructions.ts`）で頼んでいます。その文面を決めるために、正解を付けた会話を実際のハーネスに流して比べた記録です（#107。ADR 0028）。後半は、受信モード「他人宛てを除く（Jev）」で、Jev が他人宛てとして外す発言を、同じ会話で確かめた記録です（ADR 0029）。

## 方法

- 会話と流し方は `test/e2e/addressing.ts` にあります。案内を変えたときは `test/e2e/addressing.sh` で同じ評価を走らせ、基準に届かなければ失敗にします（`scripts/e2e-targets.ts` が、走らせる e2e に挙げます）。
- 会話は 2 つです。どちらも、アリス・ボブ・カオルの 3 人と Bot がいるルームで、発言ごとに正解（答える・黙る・どちらでもよい）を付けています。
  - main：案内の文面を決めるのに使った会話です（26 件）。
  - holdout：文面が main に合わせすぎていないかを確かめる会話です（25 件）。分類は同じで、言い回しを変え、迷いやすい発言を足しました。
- 答えるべき発言は、だれに向けたかを書いていない問いかけ（「この JSON、どこがおかしいんだろう」）、全員や「だれか」に向けた問い（「みんな、UTC の 15 時って日本時間だと何時だっけ？」）、Bot との会話の続き（「じゃあ、末尾のカンマを消せば読めるようになる？」）です。
- 黙るべき発言は、名前で特定の人に向けた発言（構造の印はないもの）、人どうしのやりとり、Bot が役に立てない雑談と相づちです。
- 発言は、1 つずつ、前のターンが終わってから送ります。最後の 4 件は、1.5 秒ずつ空けて続けて送ります（束。作業中のターンへの差し込みを含みます）。
- 実際の Claude Code（2.1.327、`@agentclientprotocol/claude-agent-acp` 0.101.0）と LINE の API のモックを使いました。受信モードは「すべて」です。モデルは Haiku と、Claude Code の既定のモデルです。それぞれ 3 回ずつ流しました。
- 比べた文面は 2 つです。
  - 今の文面（PR #106 の `da4e4efd`）：「`mentioned="true"` のある発言は、あなたに向けたものです（DM を含みます）。それ以外の発言は、ほかの人どうしの会話かもしれません。返事が必要なときだけ返事してください。」
  - 新しい文面：「`mentioned="true"` のある発言は、あなたに向けたものです（DM を含みます）。mentioned のない発言でも、だれに向けたかを書いていない問いかけ、全員や「だれか」に向けた問い、あなたとの会話の続きのうち、あなたが知識や作業で役に立てるものには答えてください。特定のほかの人に向けた発言と、返事を求めていない雑談や相づちには、返事しないでください。」

## 分かったこと

- 今の文面は、黙るほうへ強く押していました。Haiku では、答えるべき発言にほとんど答えず（main 3/21、holdout 0/18）、束の問いにも答えませんでした。既定のモデルでは、おおむね答えましたが、取りこぼし（main 20/21、holdout 16/18）と、人どうしのやりとりへの口出し（holdout の 6〜7 のカオルとボブのやりとりのあとに、3 回中 2 回、頼まれていない英文の例を返した）がありました。
- 新しい文面は、両方のモデル、両方の会話で、答えるべき発言すべてに答え、黙るべき発言すべてに黙りました。束でも、問いにだけ答えました。
- 「どちらでもよい」とした発言のうち、「なんでこのビルド、こんなに遅いんだろうね」（holdout の 14）と「これ、来週までにだれかやっておいてくれると嬉しいなあ」（main の 22）には、新しい文面で返事することが増えました。どちらも、手伝いを申し出る返事でした。

## 限界

- 会話は、文面を書いた人と同じ人が書きました。holdout は言い回しを変えましたが、分類は同じです。実際のルームの会話では確かめていません。
- 確かめたのは、LINE、Claude Code、受信モード「すべて」だけです。ほかのハーネス（pi、OpenCode）とチャットサービスでは流していません。「他人宛てを除く」では、構造の印のある発言は中継が外すので、エージェントに届く発言は「すべて」の一部です。
- 既定のモデルは、Claude Code がその時点で選んだものです。モデルの名前は記録していません。
- ターンの終わりは、中継のログの「ターンの出力」か、出力が止まったことで判断しています。返事が遅れると、次の発言の分に数えられます。新しい文面では、黙るべき発言の分に返事が数えられたことがないので、この取り違えは起きていません。

## Jev による他人宛ての判定（2026-11-21）

受信モード「他人宛てを除く（Jev）」（ADR 0029）で、Jev が、どの発言を他人宛てとして外すかを確かめた記録です。

### 方法

- 評価は `scripts/jev-eval.sh`（`test/e2e/addressing-jev.ts`）で流します。全件の結果は `test/fixtures/addressing-jev.json` にあります。
- 会話は、上の main と holdout に、Jev の評価だけで使う extra（18 件）を足した 3 つです（`test/e2e/conversations.ts`）。extra には、Bot の問いへの答え、ほかの人の名前を出しただけの問い（「カオルさんが言ってた Docker のエラー、どうやったら直るんだろう」）など、外してはいけない発言を多めに入れました。
- メンションのない発言を 1 つずつ、中継と同じ要求（`src/jev.ts` の `screenRequest`）で、実際の Jev（`jev-1.14.0`）に問い合わせました。直前の発言には、その会話のそれより前の発言と、Bot の返事を入れました（既定どおり 10 件まで）。Bot の返事は、上の評価で、新しい文面のエージェントが返した返事を短くしたものです。
- 正解は上の評価と同じです。外してよいのは「黙る」の発言で、「答える」の発言は 1 つも外してはいけません。「黙る」の発言には、宛先のない雑談や相づちも含みます。これは他人宛てではないので、外れなくても誤りではありません。
- 同じ会話を 3 回流しました。外すかどうかは 3 回とも同じで、同じ発言の確率の違いは 0.11 以内でした。表は 2 回目の結果です。

### 分かったこと

- 答えるべき発言は、1 つも外しませんでした。答えるべき発言の `other` は最大 0.66（extra の 5、ほかの人の名前を出しただけの問い）で、しきい値 0.8 との間に余裕があります。Bot の問いへの答え（extra の 2、6）は、`answers_agent` が 0.8 以上で、`other` も低くなりました。
- 外したのは、名前で特定の人に向けた発言（`other` 0.97〜0.99）と、それへの返事の一部（`other` 0.81〜0.82）です。返事の多くは `other` が 0.64〜0.77 で、外しませんでした。
- 宛先のない雑談と相づち（「お昼どうする？」「了解です」）は、`other` が低く、外しませんでした。これらに黙るかどうかは、案内に従って、エージェントが決めます（上の評価）。
- 「ボブさん、ついでに聞くけど、Go の goroutine ってスレッドと何が違うの？」（extra の 9）は、ボブに向けた問いとして外しました。Bot が役に立てる問いでも、名前で特定の人に向けていれば外れます。Bot に答えてほしいときは、メンションします。

### 限界

- 会話は、上の評価と同じく、文面を書いた人が書きました。実際のルームの会話では確かめていません。しきい値は、実際の記録（ログの確率）で確かめて調整します。
- Bot の返事は、実際のエージェントの返事ではなく、それを短くしたものです。
- 確かめたのは、日本語の会話だけです。
